# First App – Flutter Login & Registration UI

## 📱 Project Description

**First App** is a Flutter mobile application developed as part of a Flutter development assignment. The main purpose of this project is to practice building modern and user-friendly mobile interfaces using Flutter widgets, layouts, text fields, buttons, navigation, and basic form validation.

The application contains two main screens:

* **Login Page**
* **Registration Page**

Users can navigate between the Login and Registration pages through the provided buttons and links.

---

## ✨ Features

### 🔐 Login Page

* Application name/logo
* Email/Username input field
* Password input field
* Show/Hide password functionality
* Login button
* Forgot Password option
* Navigation to the Registration Page

## 🚀 How to Run the Project

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/Prabika524/First_App.git
```

### 2. Navigate to the Project

```bash
cd First_App
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

Connect an Android device/emulator or start an emulator and run:

```bash
flutter run
```
